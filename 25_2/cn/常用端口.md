可以。主机的**端口 port**可以理解成：
> **IP 地址定位一台主机，端口号定位这台主机上的具体应用/服务。**
例如：
```text
192.168.1.10:80    → 这台主机上的 Web 服务
192.168.1.10:22    → 这台主机上的 SSH 服务
192.168.1.10:3306  → 这台主机上的 MySQL 服务
```
端口号范围是 **0–65535**。IANA 把端口大致分成三类：**0–1023 系统/知名端口**，**1024–49151 注册端口**，**49152–65535 动态/私有端口**。([互联网分配号码机构][1])
# 1. 端口的核心作用
## 1.1 区分同一主机上的不同服务
一台服务器可以同时运行很多服务：

| 服务        |             IP |     端口 |
| --------- | -------------: | -----: |
| Web 服务    | `192.168.1.10` |   `80` |
| HTTPS 服务  | `192.168.1.10` |  `443` |
| SSH 远程登录  | `192.168.1.10` |   `22` |
| MySQL 数据库 | `192.168.1.10` | `3306` |

所以端口的作用就是：
> **让操作系统知道收到的数据应该交给哪个程序处理。**
## 1.2 支持多个网络连接同时进行
例如你打开网页时，连接可能类似：
```text
你的电脑:52341  →  服务器:443
你的电脑:52342  →  服务器:443
你的电脑:52343  →  服务器:443
```
服务器端都是 `443`，但你的电脑会使用不同的**临时端口**区分不同连接。
## 1.3 防火墙和安全控制
防火墙经常根据端口决定是否允许通信：
```text
允许 22   → 可以 SSH 远程登录
允许 80   → 可以访问 HTTP 网站
允许 443  → 可以访问 HTTPS 网站
拒绝 3306 → 外部不能访问数据库
```
所以端口也是网络安全管理的重要对象。
# 2. 端口范围分类
|            范围 | 名称                                  | 主要作用                        |
| ------------: | ----------------------------------- | --------------------------- |
|      `0–1023` | Well-known Ports / 系统端口 / 知名端口      | 常见基础协议，例如 HTTP、DNS、SMTP、SSH |
|  `1024–49151` | Registered Ports / 注册端口             | 常见应用程序、数据库、中间件等             |
| `49152–65535` | Dynamic/Private Ports / 动态端口 / 临时端口 | 客户端临时通信使用                   |

动态端口通常由操作系统自动分配，用于客户端发起连接时作为**源端口**。([互联网分配号码机构][1])
# 3. 常见系统端口：0–1023
## 3.1 文件传输类
|   端口 | 协议  | 服务          | 作用               |
| ---: | --- | ----------- | ---------------- |
| `20` | TCP | FTP Data    | FTP 数据传输         |
| `21` | TCP | FTP Control | FTP 控制连接         |
| `22` | TCP | SSH / SFTP  | 安全远程登录、SFTP 文件传输 |
| `23` | TCP | Telnet      | 明文远程登录，不安全       |
| `69` | UDP | TFTP        | 简单文件传输协议         |

## 3.2 Web 访问类
|    端口 | 协议  | 服务    | 作用     |
| ----: | --- | ----- | ------ |
|  `80` | TCP | HTTP  | 普通网页访问 |
| `443` | TCP | HTTPS | 加密网页访问 |

访问网站时，最常见就是：
```text
http://example.com   → 80
https://example.com  → 443
```
## 3.3 邮件类

| ----: | --- | --------------- | ----------- |
|  `25` | TCP | SMTP            | 邮件服务器之间传送邮件 |
| `110` | TCP | POP3            | 客户端收取邮件     |
| `143` | TCP | IMAP            | 客户端同步访问邮件   |
| `465` | TCP | SMTPS           | 加密 SMTP     |
| `587` | TCP | SMTP Submission | 邮件客户端提交邮件   |
| `993` | TCP | IMAPS           | 加密 IMAP     |
| `995` | TCP | POP3S           | 加密 POP3     |

结合你前面那页课件，可以这样记：

| 功能   | 协议         | 常见端口               |
| ---- | ---------- | ------------------ |
| 发邮件  | SMTP       | `25`, `465`, `587` |

| 网页邮箱 | HTTP/HTTPS | `80`, `443`        |

## 3.4 域名、地址分配、时间同步
|    端口 | 协议      | 服务          | 作用            |
| ----: | ------- | ----------- | ------------- |
|  `53` | UDP/TCP | DNS         | 域名解析          |
|  `67` | UDP     | DHCP Server | DHCP 服务器分配 IP |

例如访问：

# 5. 动态端口：49152–65535
这类端口一般不是固定服务端口，而是客户端临时使用。
例如你访问 HTTPS 网站：
```text
你的电脑:52618  →  服务器:443
```
其中：
```text
52618
```
就是你的电脑临时分配的动态端口。
服务器返回数据时，会发回：
```text
服务器:443  →  你的电脑:52618
```
所以动态端口的作用是：
> **让客户端同时维护多个连接。**
# 6. TCP 端口和 UDP 端口不是一回事
同一个端口号，在 TCP 和 UDP 中是两个不同的空间。
例如：

|    端口 | TCP 用途             | UDP 用途                 |
| ----: | ------------------ | ---------------------- |
|  `53` | DNS 区域传送、较大 DNS 响应 | 普通 DNS 查询              |
|  `80` | HTTP               | 某些 UDP 应用也可以占用         |
| `443` | HTTPS over TCP     | QUIC / HTTP/3 over UDP |

所以说“端口 53”时，最好说明：
```text
TCP 53
UDP 53
```
# 7. 主机端口状态
一个端口在主机上通常有几种状态：

| 状态               | 含义              |
| ---------------- | --------------- |
| Open / Listening | 有程序正在监听这个端口     |
| Closed           | 没有程序监听，但主机可达    |
| Filtered         | 被防火墙过滤，探测不到明确响应 |
| Established      | 已经建立连接          |

例如 Linux 上可以查看监听端口：
```bash
ss -tulnp
```
Windows 上可以查看端口：
```powershell
netstat -ano
```

# 9. 用 Wireshark 抓包时的端口过滤
例如抓 SMTP：
```wireshark
tcp.port == 25 or tcp.port == 465 or tcp.port == 587
```
抓 HTTP：
```wireshark
tcp.port == 80
```
抓 HTTPS：
```wireshark
tcp.port == 443
```
抓 DNS：
```wireshark
udp.port == 53 or tcp.port == 53
```
抓你前面本地 SMTP 实验的 `2525` 端口：
```wireshark
tcp.port == 2525
```
# 10. 最重要的总结
端口的作用可以总结为三句话：
1. **IP 地址定位主机，端口号定位主机上的应用进程。**
2. **服务器端口通常固定，例如 HTTP 是 80，HTTPS 是 443，SMTP 是 25/587。**
3. **客户端通常使用动态端口，例如 49152–65535，用来同时维持多个连接。**
