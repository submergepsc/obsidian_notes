# 一、TCP 套接字编程总结

## 1. TCP 的特点

TCP 是一种**面向连接**的传输协议。通信前，客户端和服务端必须先建立连接；连接建立后，双方才能进行数据收发。

TCP 的主要特点是：

|特点|说明|
|---|---|
|面向连接|通信前需要先建立连接|
|可靠传输|数据丢失会重传|
|有序传输|数据按发送顺序到达|
|面向字节流|传输的是连续字节流，不保留消息边界|

---

## 2. TCP 服务端基本流程

TCP 服务端一般流程是：

```text
创建 socket
绑定 IP 和端口
开始监听
等待客户端连接
接收客户端数据
处理数据
发送结果给客户端
关闭连接
继续等待下一个客户端
```

对应函数流程：

```text
socket()
bind()
listen()
accept()
recv()
send() / sendall()
close()
```

---

## 3. TCP 服务端核心代码

```python
import socket

HOST = "127.0.0.1"
PORT = 12000
BUFFER_SIZE = 1024

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as server_socket:
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_socket.bind((HOST, PORT))
    server_socket.listen(1)

    print(f"TCP server listening on {HOST}:{PORT}")

    while True:
        connection_socket, client_address = server_socket.accept()

        with connection_socket:
            message = connection_socket.recv(BUFFER_SIZE)

            if not message:
                continue

            modified_message = message.lower()
            connection_socket.sendall(modified_message)
```

---

## 4. TCP 客户端基本流程

TCP 客户端一般流程是：

```text
创建 socket
连接服务器
发送数据
接收服务器返回结果
关闭 socket
```

对应函数流程：

```text
socket()
connect()
sendall()
recv()
close()
```

---

## 5. TCP 客户端核心代码

```python
import socket

SERVER_HOST = "127.0.0.1"
SERVER_PORT = 12000
BUFFER_SIZE = 1024

message = input("Input uppercase sentence:")

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as client_socket:
    client_socket.connect((SERVER_HOST, SERVER_PORT))
    client_socket.sendall(message.encode("utf-8"))

    modified_message = client_socket.recv(BUFFER_SIZE)
    print(modified_message.decode("utf-8"))
```

---

## 6. TCP 中两个 socket 的区别

服务端中有两个重要 socket：

|socket|来源|作用|
|---|---|---|
|`server_socket`|`socket.socket()` 创建|监听客户端连接|
|`connection_socket`|`accept()` 返回|和某一个客户端具体通信|

需要注意：

```python
server_socket.accept()
```

不是接收数据，而是**接受客户端连接**。

真正接收数据的是：

```python
connection_socket.recv()
```

所以：

```text
accept() 负责建立连接
recv() 负责接收消息
```

---

## 7. TCP 中 sendall 为什么不需要地址？

TCP 是面向连接的。客户端已经通过：

```python
connect()
```

和服务端建立连接，服务端也通过：

```python
accept()
```

得到了对应的 `connection_socket`。

所以发送数据时直接写：

```python
connection_socket.sendall(data)
```

不需要再写客户端地址。

因为 `connection_socket` 已经知道自己对应的是哪个客户端。

# 二、UDP 套接字编程总结

## 1. UDP 的特点

UDP 是一种**无连接**的传输协议。通信前不需要建立连接，发送方直接把数据报发送给指定地址。

UDP 的主要特点是：

|特点|说明|
|---|---|
|无连接|不需要提前建立连接|
|速度快|开销小，发送简单|
|不可靠|不保证数据一定到达|
|可能乱序|不保证数据顺序|
|面向数据报|一次发送就是一个独立数据包|

---

## 2. UDP 服务端基本流程

UDP 服务端一般流程是：

```text
创建 UDP socket
绑定 IP 和端口
等待接收客户端数据
处理数据
根据客户端地址返回结果
继续等待下一条数据
```

对应函数流程：

```text
socket()
bind()
recvfrom()
sendto()
close()
```

UDP 服务端不需要：

```text
listen()
accept()
```

因为 UDP 不建立连接。

---

## 3. UDP 服务端核心代码

```python
from socket import *

SERVER_HOST = "127.0.0.1"
SERVER_PORT = 12000
BUFFER_SIZE = 2048

server_socket = socket(AF_INET, SOCK_DGRAM)
server_socket.bind((SERVER_HOST, SERVER_PORT))

print(f"UDP server listening on {SERVER_HOST}:{SERVER_PORT}")

while True:
    message, client_address = server_socket.recvfrom(BUFFER_SIZE)

    modified_message = message.upper()

    server_socket.sendto(modified_message, client_address)
```

---

## 4. UDP 客户端基本流程

UDP 客户端一般流程是：

```text
创建 UDP socket
输入数据
发送数据到服务器地址
接收服务器返回结果
关闭 socket
```

对应函数流程：

```text
socket()
sendto()
recvfrom()
close()
```

---

## 5. UDP 客户端核心代码

```python
from socket import *

SERVER_HOST = "127.0.0.1"
SERVER_PORT = 12000
BUFFER_SIZE = 2048

client_socket = socket(AF_INET, SOCK_DGRAM)

message = input("Input lowercase sentence:")

client_socket.sendto(message.encode("utf-8"), (SERVER_HOST, SERVER_PORT))

modified_message, server_address = client_socket.recvfrom(BUFFER_SIZE)

print(modified_message.decode("utf-8"))

client_socket.close()
```

---

## 6. UDP 为什么要指定地址？

UDP 没有建立连接，所以 socket 不知道这次数据要发给谁。

因此发送数据时必须写：

```python
sendto(data, address)
```

例如：

```python
client_socket.sendto(message.encode(), (SERVER_HOST, SERVER_PORT))
```

服务端回复客户端时也要写：

```python
server_socket.sendto(modified_message, client_address)
```

因为 UDP 每次发送都要明确指定目标地址。

# 三、TCP 和 UDP 对比总结

|对比项|TCP|UDP|
|---|---|---|
|socket 类型|`SOCK_STREAM`|`SOCK_DGRAM`|
|是否连接|需要连接|不需要连接|
|服务端是否 `listen()`|需要|不需要|
|服务端是否 `accept()`|需要|不需要|
|客户端是否 `connect()`|通常需要|通常不需要|
|发送函数|`send()` / `sendall()`|`sendto()`|
|接收函数|`recv()`|`recvfrom()`|
|是否可靠|可靠|不可靠|
|是否保证顺序|保证|不保证|
|典型用途|文件传输、网页访问、可靠通信|视频、语音、广播、简单报文|
