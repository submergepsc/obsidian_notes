## 1️⃣ 算术运算指令（Arithmetic）

|指令|名称来源 / 含义|
|---|---|
|`add`|**ADd**，加法运算，把两个操作数相加|
|`sub`|**SUBtract**，减法运算|
|`mul`|**MULtiply**，乘法运算|
|`div`|**DIVide**，除法运算|
|`neg`|**NEGate**，取反数，把寄存器值变成负数（-Rn）|


## 2️⃣ 逻辑运算指令（Logical）

|指令|名称来源 / 含义|
|---|---|
|`and`|按位 **AND**（与）|
|`orr`|按位 **OR**（或），用两个 R 的字符组合 `OR`，多加了 `R` 是 ARM 约定|
|`eor`|**Exclusive OR**，按位异或，简称 XOR，用 E 代替 Exclusive|
|`mvn`|**MoVe Not**，把寄存器按位取反，MVN = move + not（Rd = ~Rn）|

## 3️⃣ 移位指令（Shift）

|指令|名称来源 / 含义|
|---|---|
|`asr`|**Arithmetic Shift Right**，算术右移，符号位保持不变|
|`lsl`|**Logical Shift Left**，逻辑左移，空出的低位补 0|
|`lsr`|**Logical Shift Right**，逻辑右移，空出的高位补 0|
|`ror`|**Rotate Right**，循环右移，高位移出的位回到低位|

B<条件码> 或者BL<条件码>

|标志|含义|什么时候置位|
|---|---|---|
|**N**|Negative（负数）|运算结果为负数时 N=1|
|**Z**|Zero（零）|运算结果为 0 时 Z=1|
|**C**|Carry（进位/借位）|无符号加减法产生进位/借位时置位|
|**V**|Overflow（溢出）|有符号加减法溢出时置位|

| 条件     | 英文 / 名称来源               | 条件逻辑                     |
| ------ | ----------------------- | ------------------------ |
| **EQ** | Equal（相等）               | Z = 1 → 上次运算结果为 0        |
| **NE** | Not Equal（不等）           | Z = 0 → 上次运算结果不为 0       |
| **MI** | Minus（负数）               | N = 1 → 上次结果为负           |
| **PL** | Plus（正数）                | N = 0 → 上次结果为非负          |
| **HI** | Higher（无符号大于）           | C = 1 且 Z = 0 → 无符号大于    |
| **LO** | Lower（无符号小于）            | C = 0 → 无符号小于            |
| **LS** | Lower or Same（无符号 ≤）    | C = 0 或 Z = 1 → 无符号小于等于  |
| **GE** | Greater or Equal（有符号 ≥） | N = V → 有符号大于等于          |
| **LT** | Less Than（有符号 <）        | N != V → 有符号小于           |
| **GT** | Greater Than（有符号 >）     | Z = 0 且 N = V → 有符号大于    |
| **LE** | Less or Equal（有符号 ≤）    | Z = 1 或 N != V → 有符号小于等于 |
