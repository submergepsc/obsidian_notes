## 一、HTML 是什么？

**HTML** 全称是 **HyperText Markup Language**，中文一般叫 **超文本标记语言**。

它不是严格意义上的编程语言，而是一种**标记语言**。它的作用是告诉浏览器：网页里有哪些内容，以及这些内容大致是什么结构。

例如：

```html
<h1>这是一级标题</h1>
<p>这是一段文字。</p>
<a href="https://example.com">这是一个链接</a>
```

浏览器看到这些标签后，就知道：

```text
<h1> 表示标题
<p> 表示段落
<a> 表示链接
```

所以，HTML 主要负责网页的**内容和结构**。

---

## 二、HTML、CSS、JavaScript 的关系

一个网页通常由三部分组成：

|技术|中文|作用|类比|
|---|---|---|---|
|HTML|超文本标记语言|决定网页有什么内容|骨架|
|CSS|层叠样式表|决定网页长什么样|衣服、装修|
|JavaScript / JS|脚本语言|决定网页怎么交互|动作、功能|

例如一个按钮：

```html
<button>点击我</button>
```

HTML 负责创建按钮。

CSS 可以让按钮变大、变色、居中。

JavaScript 可以让按钮点击后弹出提示、提交表单、跳转页面等。

## 三、HTML 的基本结构

一个完整 HTML 页面通常长这样：

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>我的第一个网页</title>
</head>
<body>
  <h1>欢迎来到我的网页</h1>
  <p>这是网页中的一段文字。</p>
</body>
</html>
```

逐个解释：

|代码|含义|
|---|---|
|`<!DOCTYPE html>`|声明这是 HTML5 文档|
|`<html>`|整个网页的根标签|
|`<head>`|放网页的配置信息，一般不直接显示在页面上|
|`<meta charset="UTF-8">`|设置字符编码，避免中文乱码|
|`<title>`|浏览器标签页上的标题|
|`<body>`|网页真正显示出来的内容|

## 四、HTML 里的核心概念

### 1. 标签 Tag

HTML 用标签表示内容类型。

例如：

```html
<p>这是一段话</p>
```

其中：

```text
<p> 是开始标签
</p> 是结束标签
```

### 2. 元素 Element

从开始标签到结束标签整体叫一个元素。

```html
<p>这是一段话</p>
```

这一整段就是一个 paragraph element，也就是段落元素。

### 3. 属性 Attribute

属性用来给标签补充信息。

例如：

```html
<a href="https://example.com">点击跳转</a>
```

其中：

```text
href 是属性名
https://example.com 是属性值
```

### 4. 内容 Content

标签中间的文字、图片、按钮等就是内容。

```html
<p>这里是内容</p>
```

## 七、几个容易混淆的点

### 1. HTML 不是编程语言

HTML 不能做复杂逻辑判断，比如：

```text
如果用户点击按钮，就计算结果
如果成绩大于 60，就显示及格
循环输出 100 条数据
```

这些通常要靠 JavaScript 完成。

HTML 更像是在描述：

```text
这里有标题
这里有图片
这里有链接
这里有表格
这里有输入框
```
	
### 2. HTML 标签不等于网页样式
		
例如：

```html
<p>这是一段话</p>
```

它只说明“这是一段文字”，但这段文字是红色、蓝色、大号、小号、居中还是靠左，主要由 CSS 决定。

---

### 3. `<div>` 和 `<span>` 的区别

|标签|特点|常见用途|
|---|---|---|
|`<div>`|块级元素，默认独占一行|页面布局、容器|
|`<span>`|行内元素，不独占一行|包裹一小段文字|

例如：

```html
<div>这是一个区域</div>
<p>这是 <span>一小段特殊文字</span> 的例子。</p>
```

## 八、最简单的学习路线

建议按这个顺序学：

```text
1. HTML 基础标签
2. 表格 table
3. 表单 form
4. 语义化标签 header、nav、main、section、footer
5. CSS 基础样式
6. JavaScript 基础交互
7. 综合做一个小网页
```

你可以先把 HTML 理解成一句话：

**HTML 负责搭建网页内容结构，CSS 负责美化网页，JavaScript 负责实现交互功能。**
