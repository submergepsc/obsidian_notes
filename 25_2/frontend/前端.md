你这里应该是想问：**前端有哪些编程语言/相关语言可以写**。前端主要不是只有一种语言，而是由几类技术组成。
## 1. 前端最核心的三种
### 1）HTML
负责网页的**结构**。
比如：
```html
<h1>这是标题</h1>
<p>这是正文</p>
<button>点击我</button>
```
HTML 决定页面里有什么：
```text
标题
文字
图片
按钮
表单
链接
页面结构
```
严格来说，HTML 不是编程语言，而是**标记语言**。
### 2）CSS
负责网页的**样式**。
比如：
```css
h1 {
  color: red;
  font-size: 32px;
}
```
CSS 决定页面长什么样：
```text
颜色
字体
大小
布局
边距
背景
动画
响应式适配
```
CSS 也不是传统编程语言，更准确地说是**样式语言**。
### 3）JavaScript
负责网页的**交互和逻辑**。
比如：
```javascript
document.querySelector("button").onclick = function () {
  alert("你点击了按钮");
};
```
JavaScript 可以实现：
```text
按钮点击
登录注册
表单验证
请求后端 API
页面动态变化
数据渲染
弹窗
轮播图
聊天界面
```
这是前端最核心的真正编程语言。
## 2. 现代前端常用语言
### 1）JavaScript
前端基础必学。
适合写：
```text
普通网页
网页交互
前端项目
接口请求
浏览器脚本
```
### 2）TypeScript
TypeScript 可以理解为：
```text
JavaScript + 类型检查
```
比如 JavaScript 这样写：
```javascript
let age = 18;
```
TypeScript 可以写得更严格：
```typescript
let age: number = 18;
```
它的好处是：
```text
代码更规范
大型项目更稳定
报错更早发现
适合团队开发
```
现在很多正式前端项目都更推荐 TypeScript。
## 3. 前端框架常用什么语言？
现代前端一般不会只写原生 HTML/CSS/JS，而是会用框架。
常见框架有：

| 框架      | 主要语言                    | 适合方向        |
| ------- | ----------------------- | ----------- |
| Vue     | JavaScript / TypeScript | 国内常用，入门相对友好 |
| React   | JavaScript / TypeScript | 使用广，生态强     |
| Angular | TypeScript              | 大型企业项目较多    |
| Svelte  | JavaScript / TypeScript | 更轻量，语法简洁    |

比如 Vue 项目里会写：
```vue
<template>
  <button @click="count++">点击 {{ count }}</button>
</template>
<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>
```
## 4. 和前端有关的其他语言/技术
### 1）Sass / Less
它们是 CSS 的增强版。
普通 CSS：
```css
.box {
  color: red;
}
```
Sass/Less 可以让样式写得更方便，适合大项目。
### 2）JSON
前端和后端传数据经常用 JSON。
比如大模型 API 请求里经常见到：
```json
{
  "model": "deepseek-chat",
  "messages": [
    {
      "role": "user",
      "content": "你好"
    }
  ]
}
```
JSON 本身不是编程语言，而是**数据格式**。
### 3）Markdown
写文档、博客、说明页面常用。
例如：
```markdown
# 标题
这是正文。
```
## 5. 如果你是新手，建议学习顺序
比较稳的路线是：
```text
HTML
↓
CSS
↓
JavaScript
↓
Vue 或 React
↓
TypeScript
↓
前端工程化工具
```
如果你想快速做出一个网站，可以先学：
```text
HTML + CSS + JavaScript
```
如果你想以后做项目、管理后台、API 控制台，建议走：
```text
Vue + TypeScript
```
## 6. 简单总结
前端最核心的是：
```text
HTML：页面结构
CSS：页面样式
JavaScript：页面逻辑
```
现代前端常用的是：
```text
JavaScript
TypeScript
Vue
React
```
对于你现在这种有域名、想搭网页的情况，我建议先从：
```text
HTML + CSS + JavaScript
```
开始，先做一个能访问的简单首页。
