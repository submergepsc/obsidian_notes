# Java 实例 - 字符串格式化

- Source: https://www.runoob.com/java/string-format.html

[![Java 实例](https://www.runoob.com/images/up.gif) Java 实例](https://www.runoob.com/java-examples.html)


以下实例演示了通过 format() 方法来格式化字符串，还可以指定地区来格式化：


## StringFormat.java 文件



```java
import java.util.*;

public class StringFormat {
    public static void main(String[] args){
        double e = Math.E;
        System.out.format("%f%n", e);
        System.out.format(Locale.CHINA  , "%-10.4f%n%n", e);  //指定本地为中国（CHINA）
    }
}
```


以上代码实例输出结果为：


```
2.718282
2.7183
```
