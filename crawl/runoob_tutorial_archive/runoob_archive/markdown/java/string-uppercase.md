# Java 实例 - 字符串小写转大写

- Source: https://www.runoob.com/java/string-uppercase.html

[![Java 实例](https://www.runoob.com/images/up.gif) Java 实例](https://www.runoob.com/java-examples.html)


以下实例使用了 String toUpperCase() 方法将字符串从小写转为大写：


## StringToUpperCaseEmp.java 文件



```java
public class StringToUpperCaseEmp {
    public static void main(String[] args) {
        String str = "string runoob";
        String strUpper = str.toUpperCase();
        System.out.println("原始字符串: " + str);
        System.out.println("转换为大写: " + strUpper);
    }
}
```


以上代码实例输出结果为：


```
原始字符串: string runoob
转换为大写: STRING RUNOOB
```
