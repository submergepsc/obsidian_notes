# PostgreSQL 子查询

- Source: https://www.runoob.com/postgresql/postgresql-sub-queries.html

子查询或称为内部查询、嵌套查询，指的是在 PostgreSQL 查询中的 WHERE 子句中嵌入查询语句。


一个 SELECT 语句的查询结果能够作为另一个语句的输入值。


子查询可以与 SELECT、INSERT、UPDATE 和 DELETE 语句一起使用，并可使用运算符如 =、、>=、
