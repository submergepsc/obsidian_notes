# HTML DOM 教程

- Source: https://www.runoob.com/htmldom/htmldom-tutorial.html

**

DOM (Document Object Model) 译为文档对象模型**，是 HTML 和 XML 文档的编程接口。


HTML DOM 定义了访问和操作 HTML 文档的标准方法。


DOM 以树结构表达 HTML 文档。
