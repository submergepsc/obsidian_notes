一个网站开发人员必须掌握的知识是什么？


- HTML 和 CSS
- 客户端脚本 - JavaScript and the DOM
- 服务端脚本 - ASP, PHP
- XML 和SQL


## 指南列表


[WWW - 万维网](https://www.runoob.com/web-www.html) web站点是一个到世界各地电脑都可以连接上的网络。他是如何工作的呢?


[HTML - WEB标记语言。](https://www.runoob.com/web-html.html) 超文本标记语言（英语：HyperText Markup Language，简称：HTML）是一种用于创建网页的标准标记语言。


[CSS - 层叠样式表](https://www.runoob.com/web-css.html) 样式表定义如何显示 HTML 元素。


[JavaScript -客户端脚本](https://www.runoob.com/web-javascript.html) JavaScript 用于客户端的脚本化。客户端脚本化指的是 Web 浏览器编程。


[XML -扩展标记语言](https://www.runoob.com/web-xml.html) XML 不是 HTML 的替代者。XML 用来描述及传输数据，而 HTML 用来显示数据。


[PHP 和 ASP - 服务器端脚本化](https://www.runoob.com/web-scripting.html) 服务器端脚本化指的是服务器端编程。


[SQL - 结构化查询语言](https://www.runoob.com/web-sql.html) 结构化查询语言 (SQL) 是用来访问诸如 SQL Server、Oracle、Sybase 及 Access 等数据库的通用标准。


[Web 创建设计](https://www.runoob.com/web-design.html) 介绍关于网站的设计，及需要的开发工具。


[Web 标准](https://www.runoob.com/web-standards.html) 关于Web标准和万维网联盟.


[web 网站验证](https://www.runoob.com/web-validate.html) 这个章节将介绍关于 HTML, XHTML, CSS, XML, 和 WMP 页面标准的验证。


[Web 语义化](https://www.runoob.com/web-semantic.html) 本章节将介绍Web的语义


[Web 词汇表](https://www.runoob.com/web-glossary.html) 这是一个按字母顺序排列的互联网词汇表。


[Web 搜索引擎优化](https://www.runoob.com/web-search.html) 关于 SEO (搜索引擎优化)
