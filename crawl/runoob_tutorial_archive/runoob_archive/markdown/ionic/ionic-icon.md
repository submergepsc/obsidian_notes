# ionic icon(图标)

- Source: https://www.runoob.com/ionic/ionic-icon.html

ionic 也默认提供了许多的图标，大概有 700 多个，针对 Android 和 iOS 有不同的样式。


Ionic icons 官网: [http://ionicons.com/](http://ionicons.com/)


国内图标样式 CDN 地址：[https://cdn.staticfile.net/ionicons/2.0.1/css/ionicons.min.css](https://cdn.staticfile.net/ionicons/2.0.1/css/ionicons.min.css)。


用法也非常的简单，由一个 icon 类及指定图标类组成，如：


## 实例


```
<i class="icon ion-star"></i>
<i class = "icon ion-happy-outline"></i>
<i class = "icon ion-ios-analytics"></i>
<i class = "icon ion-ios-eye"></i>
```


**
[尝试一下 »](https://www.runoob.com/try/try.php?filename=tryionic_icon)


我们可以通过 font-size 来设置图片的大小：


## 实例


```
.icon {
   font-size: 50px;
}
```
