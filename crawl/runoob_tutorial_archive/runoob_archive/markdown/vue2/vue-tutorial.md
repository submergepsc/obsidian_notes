# Vue.js 教程

- Source: https://www.runoob.com/vue2/vue-tutorial.html

![Angular](https://www.runoob.com/wp-content/uploads/2017/01/vue.png)

Vue.js（读音 /vjuː/, 类似于 view） 是一套构建用户界面的渐进式框架。


Vue 只关注视图层， 采用自底向上增量开发的设计。

Vue 的目标是通过尽可能简单的 API 实现响应的数据绑定和组合的视图组件。


Vue 学习起来非常简单，本教程基于 Vue 2.1.8 版本测试，Vue3 请参阅 [Vue3 教程](https://www.runoob.com/../vue3/vue3-tutorial.html)。


Vue 2.0 在 2023 年 12 月 31 日停止更新。
