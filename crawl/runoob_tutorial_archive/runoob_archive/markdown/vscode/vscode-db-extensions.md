# VSCode 数据库客户端扩展

- Source: https://www.runoob.com/vscode/vscode-db-extensions.html

本章节我们主要介绍下平时开发常用的一些数据库客户端扩展：


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-0.webp)


---

## 1、SQLTools


SQLTools 是一款开源的数据库管理扩展，支持多种常用数据库，包括MySQL、PostgreSQL、Microsoft SQL Server、SQLite 等。


SQLTools 以轻量和高效著称，提供数据库连接、查询执行和结果展示等功能。


扩展搜索关键词：**SQLTools**


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-1.webp)


插件链接地址：[https://marketplace.visualstudio.com/items?itemName=mtxr.sqltools](https://marketplace.visualstudio.com/items?itemName=mtxr.sqltools)


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-2.webp)


安装后需根据数据库类型安装对应的驱动扩展，搜索 **@tag:sqltools-driver** 将列出所有适用于 SQLTools 的驱动程序。


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-3.webp)


---

## 2、MSSQL


MSSQL 由 Microsoft 官方开发，专为 SQL Server 和 Azure SQL 数据库设计的扩展。


MSSQL 提供了强大的 T-SQL 脚本支持和数据库管理功能，适合 SQL Server 开发者。


扩展搜索关键词：**MSSQL**


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-4.webp)


插件链接地址：[https://marketplace.visualstudio.com/items?itemName=ms-mssql.mssql](https://marketplace.visualstudio.com/items?itemName=ms-mssql.mssql)


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-5.webp)


---

## 3、Database Client


Database Client 是一款支持多种数据库的扩展，包括 MySQL、PostgreSQL、SQLite、Redis、ClickHouse 等。


Database Client 提供基本的数据库管理和备份功能，适合需要通用解决方案的开发者。


扩展搜索关键词：**Database Client**


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-6.webp)


插件链接地址：[https://marketplace.visualstudio.com/items?itemName=cweijan.vscode-database-client2](https://marketplace.visualstudio.com/items?itemName=cweijan.vscode-database-client2)


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-7.webp)


打开左侧数据库面板，点击添加按钮，在连接页面配置相应的数据库信息：


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-8.webp)


---

## 4、DBCode


DBCode 是一款功能强大的数据库管理扩展，支持 PostgreSQL、MySQL、MariaDB、SQL Server、SQLite、MongoDB 等多种数据库。


DBCode 不仅提供基本的数据库操作，还集成了 AI 查询和数据可视化功能。


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-9.webp)


扩展搜索关键词：**DBCode**


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-10.webp)


插件链接地址：[https://marketplace.visualstudio.com/items?itemName=DBCode.dbcode](https://marketplace.visualstudio.com/items?itemName=DBCode.dbcode)


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-11.webp)


---


## 5、DevDb


DevDb 是一款轻量级数据库管理扩展，支持 SQLite、MySQL、PostgreSQL 和 SQL Server。


DevDb 适合轻量级项目或需要在开发过程中快速查看和编辑数据库的开发者。


扩展搜索关键词：**DevDb**


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-12.webp)


插件链接地址：[https://marketplace.visualstudio.com/items?itemName=damms005.devdb](https://marketplace.visualstudio.com/items?itemName=damms005.devdb)

## 6、MongoDB for VS Code


MongoDB for VS Code 是由 MongoDB 官方提供的扩展，专为 MongoDB 数据库设计，支持本地和云端（MongoDB Atlas）实例的管理。


MongoDB for VS Code 提供直观的数据浏览、查询原型设计和脚本执行功能，适合 NoSQL 开发者。


扩展搜索关键词：**MongoDB for VS Code**


![](https://www.runoob.com/wp-content/uploads/2025/05/vscode-sql-16.webp)


插件链接地址：[https://marketplace.visualstudio.com/items?itemName=mongodb.mongodb-vscode](https://marketplace.visualstudio.com/items?itemName=mongodb.mongodb-vscode)
