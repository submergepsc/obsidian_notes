# VS Code 活动栏

- Source: https://www.runoob.com/vscode/vscode-activity-bar.html

活动栏（Activity Bar）是 VS Code 左侧的一个垂直工具栏，它提供了快速访问不同功能和视图的入口。


通过活动栏，用户可以轻松切换文件资源管理器、搜索、源代码管理、调试、扩展等功能。


![](https://www.runoob.com/wp-content/uploads/2024/12/42197912-e62c-4106-884b-b2f79d366248.png)

---


## 活动栏的主要功能


### 1. 文件资源管理器（Explorer）


文件资源管理器是活动栏中的第一个图标，通常是一个文件夹的图标，点击后，它会显示当前工作区中的所有文件和文件夹。你可以在这里浏览、打开、创建、删除或重命名文件。


![](https://www.runoob.com/wp-content/uploads/2025/03/4fe362bd-e4b1-4e7c-a6b1-c9a2e1740381.png)


### 2. 搜索（Search）


搜索功能允许你在整个项目中查找特定的文本或代码片段,点击搜索图标（放大镜）后，你可以输入关键词，VS Code 会在项目中匹配并显示所有相关结果。


![](https://www.runoob.com/wp-content/uploads/2025/03/972768c9-ca4d-4473-a084-d2722ac832cb.png)


可以在输入框中设置文件类型以及要排除的文件。


### 3. 源代码管理（Source Control）


源代码管理功能集成了 Git，允许你在 VS Code 中直接进行版本控制操作，我们可以查看文件的更改状态、提交代码、创建分支等。


![](https://www.runoob.com/wp-content/uploads/2025/03/acfcf7de-716b-4e47-bc2f-1c0bb64d8725.png)


### 4. 调试（Debug）


调试功能是 VS Code 中非常强大的工具之一，我们可以设置断点、逐步执行代码、查看变量值等，帮助你快速定位和修复代码中的问题。


![](https://www.runoob.com/wp-content/uploads/2025/03/8b4d20b9-c3d7-469c-b2ae-6a5853dd5c0b.png)


### 5. 扩展（Extensions）


扩展功能允许你安装和管理 VS Code 的插件。

通过扩展，我们可以为 VS Code 添加新的语言支持、主题、工具等功能，极大地扩展了编辑器的功能。


![](https://www.runoob.com/wp-content/uploads/2025/03/74cad9ea-5094-4fd9-92e1-315a75c789a7.png)

## 自定义活动栏


VS Code 允许用户自定义活动栏的显示内容，可以右击状态栏，控制功能图标是否显示，打勾☑️的表示显示，反之，不显示：


![](https://www.runoob.com/wp-content/uploads/2025/03/dfd659a4-1b03-434b-b724-da26151516e0.png)

也可以设置状态栏显示在右侧：


![](https://www.runoob.com/wp-content/uploads/2025/03/4ccb2df8-f142-475d-846c-9664f275b48f.png)


不习惯右侧右击活动栏，可以调回来：
