# Rust 条件语句

- Source: https://www.runoob.com/rust/rust-conditions.html

在 Rust 语言中的条件语句是这种格式的：


## 实例


```rust
fn main() {
    let number = 3;
    if number < 5 {
        println!("条件为 true");
    } else {
        println!("条件为 false");
    }
}
```


在上述程序中有条件 if 语句，这个语法在很多其它语言中很常见，但也有一些区别：首先，条件表达式 number
