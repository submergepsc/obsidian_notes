# PHP array_flip() 函数

- Source: https://www.runoob.com/php/func-array-flip.html

[![PHP Array Reference](https://www.runoob.com/images/up.gif)完整的 PHP Array 参考手册](https://www.runoob.com/php-ref-array.html)


## 实例


反转数组中的键名和对应关联的键值：


```php
<?php
	$a1=array("a"=>"red","b"=>"green","c"=>"blue","d"=>"yellow");
	$result=array_flip($a1);print_r($result);?>
```


**[运行实例 »](https://www.runoob.com/try/showphp.php?filename=demo_func_array_flip)


---


## 定义和用法


array_flip() 函数用于反转/交换数组中的键名和对应关联的键值。


---


## 语法


array_flip(*array*);


| 参数 | 描述 |
| --- | --- |
| array | 必需。规定需进行键/值对反转的数组。 |


## 技术细节


| 返回值： | 如果反转成功，则返回反转后的数组。如果反转失败，则返回 NULL。 |
| --- | --- |
| PHP 版本： | 4+ |
