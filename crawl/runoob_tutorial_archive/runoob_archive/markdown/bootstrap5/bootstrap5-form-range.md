# Bootstrap5 选择区间

- Source: https://www.runoob.com/bootstrap5/bootstrap5-form-range.html

要设置一个选择区间可以在 **input** 元素中添加 **type="range"** 并使用 **.form-range** 类：


选择区间：


![](https://www.runoob.com/wp-content/uploads/2022/02/DB8048D0-C80D-41C0-8378-07089820C681.jpg)


## 实例


```css
<label for="customRange" class="form-label">Custom range</label>
<input type="range" class="form-range" id="customRange">
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=trybs5_form_range)

## 步长


默认情况下，步长为 1，可以通过 step 属性来设置：


## 实例


```css
<input type="range" class="form-range" step="10">
```


[尝试一下 »](https://www.runoob.com/try/try.php?filename=trybs5_form_range_step)

## 最大最小值


默认情况下，最小值为 0，最大值为 100，可以通过 min（最小） 或 max（最大） 属性来设置：


## 实例


```css
<input type="range" class="form-range" min="0" max="4">
```


[尝试一下 »](https://www.runoob.com/try/try.php?filename=trybs5_form_range_minmax)
