# Bootstrap5 Jumbotron

- Source: https://www.runoob.com/bootstrap5/bootstrap5-jumbotron.html

Jumbotron（超大屏幕）会创建一个大的灰色背景框，里面可以设置一些特殊的内容和信息。


在 Bootstrap 3 中引入了一个 jumbotron 来创建一个大的背景框，用于显示一些重要的信息。


在 Bootstrap 5 中，已经不再支持 Jumbotron。但是，我们可以使用  元素添加一些辅助类与颜色类来达到相同的效果：


**提示:** Jumbotron 里头可以放一些 HTML标签，也可以是 Bootstrap 的元素。


![](https://www.runoob.com/wp-content/uploads/2017/10/F12388F2-21CA-41BA-B7B5-250A17623D0A.jpg)


## 实例


```css
<div class="mt-4 p-5 bg-primary text-white rounded">
  <h1>菜鸟教程</h1>
  <p>学的不仅是技术，更是梦想！！！</p>
</div>
```
