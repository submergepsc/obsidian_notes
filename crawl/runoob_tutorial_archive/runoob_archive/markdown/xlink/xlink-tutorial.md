# XLink 和 XPointer 教程

- Source: https://www.runoob.com/xlink/xlink-tutorial.html

**

XLink 定义在 XML 文档中创建超级链接的标准方法。


XPointer 允许这些超级链接指向 XML 文档中的更多具体部分（片断）。


[现在开始学习 XLink 和 XPointer!](https://www.runoob.com/xlink-intro.html)**

[XLink 实例](https://www.runoob.com/xlink-example.html) 一个在 XML 文档中使用 XLink 的实例。


[XPointer 实例](https://www.runoob.com/xpointer-example.html) 一个在 XML 文档中使用 XLink 和 XPointer 的实例。


[XLink 总结](https://www.runoob.com/xlink-summary.html) 本文包括在本教程所学内容的一个总结，以及我们向你推荐的下一步应该学习的内容。
