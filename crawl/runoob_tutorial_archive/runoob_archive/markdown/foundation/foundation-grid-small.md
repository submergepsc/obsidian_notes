# Foundation 网格 - 小型设备

- Source: https://www.runoob.com/foundation/foundation-grid-small.html

假设我们在小型设备上有一个简单的网格布局，两列，宽度比例为 25% 和 75%。


**提示:** 小型设备的定义是屏幕小于 `40.0625em`。


小型设备上我们使用 `.small-*` 类。


```
<div class="small-3 columns">....</div>
<div class="small-9 columns">....</div>
```


以下实例设置了两个列，比例为 25% 和 75% (Foundation 是移动优先: 如果没有特别说明，在大型设备上会继承 .small 类的代码): `.small` in them and use those".


### 实例


```
<div
	class="row">  <div class="small-3
	columns" style="background-color:yellow;">    <p>菜鸟教程</p>  </div>  <div class="small-9
	columns" style="background-color:pink;">
	    <p>菜鸟教程</p>  </div></div>
```


**
[尝试一下 »](https://www.runoob.com/try/try2.php?filename=tryfoundation_grid_small)


|  | 注意: 要保证数列加起来是 12 列! |
| --- | --- |
