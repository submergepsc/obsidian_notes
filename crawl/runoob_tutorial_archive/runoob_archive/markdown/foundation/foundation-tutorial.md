# Foundation5 教程

- Source: https://www.runoob.com/foundation/foundation-tutorial.html

![](https://www.runoob.com/wp-content/uploads/2015/11/foundation-starter@128.png)


Foundation 用于开发响应式的 HTML, CSS and JavaScript 框架。

Foundation 是一个易用、强大而且灵活的框架,用于构建基于任何设备上的 Web 应用。


Foundation 是一个以移动优先的流行框架。
