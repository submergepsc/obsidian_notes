# Foundation 列表

- Source: https://www.runoob.com/foundation/foundation-lists.html

在 HTML 中，无序列表 (``) 实例如下:


```
<ul>  <li>List item</li>  <li>List item</li>  <li>List item</li>
	  <li>List item</li></ul>
```


结果:


- List item
- List item
- List item
- List item


### 圆圈标识符


在 Foundation 中，无序列表 (``) 的前缀符号为圆圈，使用 .circle 类，实例如下:


```
<ul class="circle">  <li>List item</li>  ...</ul>
```


**
[尝试一下 »](https://www.runoob.com/try/try2.php?filename=tryfoundation_list_circle)


### 方块标识符


方块标识符前缀使用 .square 类:


```
<ul class="square">  <li>List item</li>  ...</ul>
```


[尝试一下 »](https://www.runoob.com/try/try2.php?filename=tryfoundation_list_square)


### 无标识符


如果你不需要标识符，你可以使用 .no-bullet 类：


```
<ul class="no-bullet">  <li>List item</li>  ...</ul>
```


[尝试一下 »](https://www.runoob.com/try/try2.php?filename=tryfoundation_list_no-bullet)


如果你需要添加一个水平的列表，可以在 `` 上添加 `.inline-list` 类:


```
<ul class="inline-list">
```


[尝试一下 »](https://www.runoob.com/try/try2.php?filename=tryfoundation_list_inline)

## 列表菜单


一些 Web 页面可能需要列表菜单。


在 HTML 中，列表菜单同无序列表 `` 来定义，例如:


```
<ul>  <li><a href="#">Home</a></li>  <li><a
	href="#">Menu 1</a></li>  <li><a href="#">Menu 2</a></li>
	<li><a href="#">Menu 3</a></li></ul>
```


结果:


- Home
- Menu 1
- Menu 2
- Menu 3
