# jQuery UI 教程

- Source: https://www.runoob.com/jqueryui/jqueryui-tutorial.html

jQuery UI 是建立在 jQuery JavaScript 库上的一组用户界面交互、特效、小部件及主题。无论您是创建高度交互的 Web 应用程序还是仅仅向窗体控件添加一个日期选择器，jQuery UI 都是一个完美的选择。


jQuery UI 包含了许多维持状态的小部件（Widget），因此，它与典型的 jQuery 插件使用模式略有不同。所有的 jQuery UI 小部件（Widget）使用相同的模式，所以，只要您学会使用其中一个，您就知道如何使用其他的小部件（Widget）。


**[现在开始学习 jQuery UI！](https://www.runoob.com/jqueryui-intro.html)**


## 从实例开始


为了更好地体验什么是 jQuery UI，请查看 [jQuery UI 实例](https://www.runoob.com/jqueryui-examples.html)。


在实例演示部分，导航列出了 jQuery UI 提供的所有交互部件和小部件。选择一个交互部件或小部件，您将看到特定插件的一些演示配置。在每个演示中，您可以查看源代码，更改主题，且 URL 可以被添加书签。例如，您可以查看 [折叠面板部件填充空间](https://www.runoob.com/try/tryit.php?filename=jqueryui-example-accordion-fillspace) 实例演示页面。
