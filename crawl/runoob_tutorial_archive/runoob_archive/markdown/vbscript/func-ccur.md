# VBScript CCur 函数

- Source: https://www.runoob.com/vbscript/func-ccur.html

---

[![VBScript 参考手册](https://www.runoob.com/images/up.gif) 完整的 VBScript 参考手册](https://www.runoob.com/vbscript-ref-functions.html)

---


CCur 函数把表达式转换为货币（Currency）类型。


表达式必须是一个数值。


### 语法


CCur(expression)


**
| 参数 | 描述 |
| --- | --- |
| expression | 必需。任何有效的表达式。 |


## 实例


## 实例 1


```
<script type="text/vbscript">
document.write(CCur(30) & "<br />")
</script>
```


以上实例输出结果：


```
30
```


[尝试一下 »](https://www.runoob.com/try/try.php?filename=vbdemo_ccur_func)


## 实例 2


请注意，CCur 函数四舍五入到4位小数：


```
<script type="text/vbscript">
document.write(CCur(5.9555555555555) & "<br />")
</script>
```


以上实例输出结果：


```
5.9556
```


[尝试一下 »](https://www.runoob.com/try/try.php?filename=vbdemo_ccur_func2)
