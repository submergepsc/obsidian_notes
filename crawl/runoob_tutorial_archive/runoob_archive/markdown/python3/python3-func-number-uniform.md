## 描述


**uniform()** 方法将随机生成下一个实数，它在 **[x,y]** 范围内。

---


## 语法


以下是 uniform() 方法的语法:


```
import random

random.uniform(x, y)
```


**注意：**uniform()是不能直接访问的，需要导入 random 模块，然后通过 random 静态对象调用该方法。


---


## 参数


- x -- 随机数的最小值，包含该值。
- y -- 随机数的最大值，包含该值。
