## 描述


clear() 方法用于移除集合中的所有元素。


## 语法


clear()方法语法：


```
set.clear()
```


## 参数


- 无。


## 返回值


无。


## 实例


移除 fruits 集合中的所有元素：


## 实例 1


```python
fruits = {"apple", "banana", "cherry"}
fruits.clear()
print(fruits)
```


输出结果为：


```python
set()
```
