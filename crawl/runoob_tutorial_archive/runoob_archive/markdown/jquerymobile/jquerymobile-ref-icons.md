# jQuery Mobile 图标

- Source: https://www.runoob.com/jquerymobile/jquerymobile-ref-icons.html

我们可以使用图标类在 jQuery Mobile 中  和  元素上添加图标，并对图标进行定位，如下所示：

**
	<a href="#anylink" class="ui-btn ui-icon-refresh ui-btn-icon-left**">刷新页面</a>
[尝试一下](https://www.runoob.com/try/tryit.php?filename=tryjqmob_icons_a)

**

	<button class="ui-btn ui-icon-refresh ui-btn-icon-left**">刷新页面</button>
	[尝试一下](https://www.runoob.com/try/tryit.php?filename=tryjqmob_icons_button)
	**

在  按钮中添加图标，可以使用 data-icon 属性:


	<a href="#anylink" data-icon="refresh"**>刷新页面</a>
	[尝试一下](https://www.runoob.com/try/tryit.php?filename=tryjqmob_icons_input)
	**

我们可以使用 data-icon 属性在导航按钮上添加图标:


	<a href="#anylink" data-icon="refresh"**>刷新页面</a>
	[尝试一下](https://www.runoob.com/try/tryit.php?filename=tryjqmob_icons_navbar)
	**

如果要在列表按钮中添加图标，可以在  中使用 data-icon 属性：


<li data-icon="refresh"**><a href="#">点我</a></li>
	[尝试一下](https://www.runoob.com/try/tryit.php?filename=tryjqmob_icons_list)
	**
