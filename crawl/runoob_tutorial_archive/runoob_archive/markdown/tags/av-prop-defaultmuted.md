## 实例


设置视频默认静音：


```
myVid=document.getElementById("video1");myVid.defaultMuted=true;
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=tryhtml5_av_prop_defaultmuted)


---


## 定义和用法


defaultMuted 属性设置或返回音频/视频是否默认静音。


设置该属性仅会改变默认的静音状态，而不是当前的。要改变当前的静音状态，请使用 [muted](https://www.runoob.com/av-prop-muted.html) 属性。


---


## 浏览器支持


![Internet Explorer](https://www.runoob.com/images/incompatible_ie.gif)![Firefox](https://www.runoob.com/images/incompatible_firefox.gif)![Opera](https://www.runoob.com/images/incompatible_opera.gif)![Google Chrome](https://www.runoob.com/images/compatible_chrome.gif)![Safari](https://www.runoob.com/images/compatible_safari.gif)


只有 Chrome 和 Safari 6 支持 defaultMuted 属性。


---


## 语法


设置 defaultMuted 属性：


	*audio|video*.defaultMuted=true|false

返回 defaultMuted 属性：


	*audio|video*.defaultMuted

## 属性值


| 值 | 描述 |
| --- | --- |
| true | 指示音频/视频默认是静音的。 |
| false | 默认。指示音频/视频默认不是静音的。 |


## 技术细节


| 返回值： | 布尔值，true\|false |
| --- | --- |
| 默认值： | false |
