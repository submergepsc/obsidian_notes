## 实例


如何定义时间和日期：


```
<p>我们在每天早上 <time>9:00</time> 开始营业。</p>

<p>我在 <time datetime="2016-02-14">情人节</time> 有个约会。</p>
```

## 标签定义及使用说明


 标签定义公历的时间（24 小时制）或日期，时间和时区偏移是可选的。


该元素能够以机器可读的方式对日期和时间进行编码，这样，举例说，用户代理能够把生日提醒或排定的事件添加到用户日程表中，搜索引擎也能够生成更智能的搜索结果。


---


## HTML 4.01 与 HTML5之间的差异


 标签是 HTML5 中的新标签。


---


## 属性


New ：HTML5 中的新属性。


| 属性 | 值 | 描述 |
| --- | --- | --- |
| datetimeNew | datetime | 规定日期/时间。另一种方式，则是由元素的内容给定日期/时间。 |
| pubdate | datetime | (该属性仍在被 WHATWG 和 W3C 组织设计和讨论中。) 指示 元素中的日期 / 时间是文档（或最近的前辈 元素）的发布日期 |
