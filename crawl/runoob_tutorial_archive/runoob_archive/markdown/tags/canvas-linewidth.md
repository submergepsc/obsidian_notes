## 实例


用宽度为 10 像素的线条来绘制矩形：


YourbrowserdoesnotsupporttheHTML5canvastag.


JavaScript：


```
var c=document.getElementById("myCanvas");
var ctx=c.getContext("2d");
ctx.lineWidth=10;
ctx.strokeRect(20,20,80,100);
```

## 定义和用法


lineWidth 属性设置或返回当前线条的宽度，以像素计。


| 默认值： | 1 |
| --- | --- |
| JavaScript 语法： | context.lineWidth=number; |


## 属性值


| 值 | 描述 |
| --- | --- |
| number | 当前线条的宽度，以像素计。 |
