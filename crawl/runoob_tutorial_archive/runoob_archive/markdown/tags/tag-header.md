## 标签定义及使用说明


 标签定义文档或者文档的一部分区域的页眉。


 元素应该作为介绍内容或者导航链接栏的容器。


在一个文档中，您可以定义多个  元素。


**注释：** 标签不能被放在 、 或者另一个  元素内部。


---


## HTML 4.01 与 HTML5之间的差异


 标签是 HTML 5 中的新标签。
