<hr>

<p>CSS 定义如何显示 HTML 元素。</p>

## 标签定义及使用说明


 标签定义 HTML 页面中的主题变化（比如话题的转移），并显示为一条水平线。


 元素被用来分隔 HTML 页面中的内容（或者定义一个变化）。


---


## HTML 4.01 与 HTML5之间的差异


在 HTML5 中， 定义内容中的主题变化，并显示为一条水平线。


在 HTML 4.01 中， 标签仅仅显示为一条水平线。


在 HTML 4.01 中，所有的布局属性都 已废弃。在 HTML5 中不再支持这些属性。请使用 CSS 来为  元素定义样式。


---


## HTML 与 XHTML 之间的差异


在 HTML 中， 标签没有结束标签。

## 属性


| 属性 | 值 | 描述 |
| --- | --- | --- |
| align | left center right | HTML5 不支持。HTML 4.01 已废弃。 规定 元素的对齐方式 |
| noshade | noshade | HTML5 不支持。HTML 4.01 已废弃。 规定 元素的颜色呈现为纯色。 |
| size | pixels | HTML5 不支持。HTML 4.01 已废弃。 规定 元素的高度。 |
| width | pixels % | HTML5 不支持。HTML 4.01 已废弃。 规定 元素的宽度。 |
