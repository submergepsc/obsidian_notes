无。

## 提示和注释


注释：**根据 HTML 5 的规范， 标签应该做为最后的选择，只有在没有其他标记比较合适时才使用它。HTML 5 规范声明：标题应该用 [ - ](https://www.runoob.com/tag-hn.html) 标签表示，被强调的文本应该用 [*](https://www.runoob.com/tag-em.html) 标签表示，重要的文本应该用 [**](https://www.runoob.com/tag-strong.html) 标签表示，被标记的或者高亮显示的文本应该用 [](https://www.runoob.com/tag-mark.html) 标签表示。


提示：**您也可以使用 CSS 的 "font-weight" 属性设置粗体文本。
