## 标签定义及使用说明


 标签定义作品（比如书籍、歌曲、电影、电视节目、绘画、雕塑等等）的标题。


注释：**人名不属于作品的标题。


---


## HTML 4.01 与 HTML5之间的差异


在 HTML5 中， 标签定义作品的标题。


在 HTML 4.01 中， 标签定义一个引用。
