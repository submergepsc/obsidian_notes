## 标签定义及使用说明


 标签定义文档或者文档的一部分区域的页脚。


 元素应该包含它所包含的元素的信息。


在典型情况下，该元素会包含文档创作者的姓名、文档的版权信息、使用条款的链接、联系信息等等。


在一个文档中，您可以定义多个  元素。


---


## HTML 4.01 与 HTML5之间的差异


 标签是 HTML 5 中的新标签。

## 提示和注释


**提示：**假如您使用  元素来插入联系信息，应该在  元素内使用 [](https://www.runoob.com/tag-address.html) 标签。
