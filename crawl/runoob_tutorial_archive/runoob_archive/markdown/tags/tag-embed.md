## 标签定义及使用说明


 标签定义了一个容器，用来嵌入外部应用或者互动程序（插件）。


> 注意**：现在已经不建议使用  标签了，可以使用 、、、 等标签代替。


---


## HTML 4.01 与 HTML5之间的差异


 标签是 HTML 5 中的新标签。


---


## 属性


New ：HTML5 中的新属性。


| 属性 | 值 | 描述 |
| --- | --- | --- |
| heightNew | pixels | 规定嵌入内容的高度。 |
| srcNew | URL | 规定被嵌入内容的 URL。 |
| typeNew | MIME_type | 规定嵌入内容的 MIME 类型。注：MIME = Multipurpose Internet Mail Extensions。 |
| widthNew | pixels | 规定嵌入内容的宽度。 |


## 全局属性


 标签支持 [HTML 的全局属性](https://www.runoob.com/ref-standardattributes.html)。

## 事件属性


 标签支持 [HTML 的事件属性](https://www.runoob.com/ref-eventattributes.html)。
