# HTML5 onbeforeprint 事件属性

- Source: https://www.runoob.com/tags/ev-onbeforeprint.html

[![HTML 事件属性](https://www.runoob.com/images/up.gif) HTML 事件属性](https://www.runoob.com/ref-eventattributes.html)


## 实例


在页面设置打印，但在打印对话框出现前执行 JavaScript :


```
<body onbeforeprint="printmsg()">
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=tryhtml5_ev_onbeforeprint)

## 浏览器支持


| 事件 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| onbeforeprint | 63 | Yes | Yes | 13 | 50 |


---


## 定义和用法


onbeforeprint 属性在用户设置页面打印，但在打印对话框出现前触发。


提示：** onbeforeprint 属性通常与 [onafterprint](https://www.runoob.com/ev-onafterprint.html) 属性一起使用。


---


## HTML 4.01 与 HTML5之间的差异


onbeforeprint 属性是HTML5新属性。


---


## 语法


    <*element* onbeforeprint="*script*">


## 属性值


| 值 | 描述 |
| --- | --- |
| script | onafterprint中执行的脚本。 |
