## 标签定义及使用说明


 标签定义运行中的任务进度（进程）。


---


## HTML 4.01 与 HTML5之间的差异


 标签是 HTML5 中的新标签。


---


## 提示和注释


**提示：**请将  标签与 JavaScript 一起使用来显示任务的进度。


**注释：** 标签不适合用来表示度量衡（例如，磁盘空间使用情况或相关的查询结果）。表示度量衡，请使用 [](https://www.runoob.com/tag-meter.html) 标签代替。


---


## 属性


New ：HTML5 中的新属性。


| 属性 | 值 | 描述 |
| --- | --- | --- |
| maxNew | number | 规定需要完成的值。 |
| valueNew | number | 规定进程的当前值。 |
