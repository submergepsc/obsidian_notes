# CSS3 :enabled 选择器

- Source: https://www.runoob.com/cssref/sel-enable.html

[![CSS完整选择器](https://www.runoob.com/images/up.gif)完整CSS选择器参考手册](https://www.runoob.com/css-selectors.html)


## 实例


设置所有type="text"的启用的输入元素的背景颜色：


```css
input[type="text"]:enabled
	{
	background:#ffff00;
	}
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=trycss3_enabled_disabled)


---


## 定义和用法


:enabled 选择器匹配每个启用的的元素（主要用于表单元素）。


---


## 浏览器支持


表格中的数字表示支持该属性的第一个浏览器版本号。


| 选择器 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| :enabled | 4.0 | 9.0 | 3.5 | 3.2 | 9.6 |
