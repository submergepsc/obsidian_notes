# CSS :focus 选择器

- Source: https://www.runoob.com/cssref/sel-focus.html

[![CSS完整选择器](https://www.runoob.com/images/up.gif)完整CSS选择器参考手册](https://www.runoob.com/css-selectors.html)


## 实例


一个输入字段获得焦点时选择的样式：


```css
input:focus
	{
	background-color:yellow;
	}
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=trycss_sel_focus)


---


## 定义和用法


:focus选择器用于选择具有焦点的元素。


提示:** :focus选择器接受键盘事件或其他用户输入的元素。


---


## 浏览器支持


表格中的数字表示支持该属性的第一个浏览器版本号。


| 选择器 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| :focus | 4.0 | 8.0 | 2.0 | 3.1 | 9.6 |


**注意:** :focus 选择器选择器在IE8中必须声明[](https://www.runoob.com/../tags/tag-doctype.html) .
