# CSS :after 选择器

- Source: https://www.runoob.com/cssref/sel-after.html

[![CSS完整选择器](https://www.runoob.com/images/up.gif)完整CSS选择器参考手册](https://www.runoob.com/css-selectors.html)


## 实例


每个元素之后插入内容：


```css
p:after
{
    content:"- Remember this";
}
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=trycss_sel_after)

## 定义和说明


:after 选择器向选定元素的最后子元素后面插入内容。


使用[content](https://www.runoob.com/pr-gen-content.html) 属性来指定要插入的内容。


---


## 浏览器支持


表格中的数字表示支持该属性的第一个浏览器版本号。


| 选择器 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ::after | 4.0 | 9.0部分从 8.0 | 3.5 | 3.1 | 7.0部分从4.0 |


注意：** after在IE8中运行，必须声明[](https://www.runoob.com/../tags/tag-doctype.html) .
