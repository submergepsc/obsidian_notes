# CSS3 :last-child 选择器

## 实例


指定父元素中最后一个p元素的背景色：


```css
p:last-child
{
    background:#ff0000;
}
```


**[尝试一下 »](https://www.runoob.com/try/try.php?filename=trycss3_last-child)


---


## 定义和用法


:last-child 选择器用来匹配父元素中最后一个子元素。


提示:** p:last-child 等同于 p:nth-last-child(1)。


---


## 浏览器支持


| 选择器 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| :last-child | 4.0 | 9.0 | 3.5 | 3.2 | 9.6 |
