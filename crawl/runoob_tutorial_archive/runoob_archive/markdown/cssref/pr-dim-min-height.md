# CSS min-height 属性

- Source: https://www.runoob.com/cssref/pr-dim-min-height.html

**
## 实例


设置段落的最低高度：


```css
p
{
    min-height:100px;
}
```




[尝试一下 »](https://www.runoob.com/try/try.php?filename=trycss_dim_min-height)


---


## 属性定义及使用说明


min-height 属性设置元素的最低高度。


注意：** min-height属性不包括填充，边框，或页边距！


| 默认值： | 0 |
| --- | --- |
| 继承： | no |
| 版本： | CSS2 |
| JavaScript 语法： | object.style.minHeight="10px" |

**
---


## 浏览器支持


表格中的数字表示支持该属性的第一个浏览器版本号。


| 属性 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| min-height | 1.0 | 7.0 | 3.0 | 2.0.2 | 4.0 |


---


## 属性值


| 值 | 描述 |
| --- | --- |
| length | 定义元素的最小高度。默认值是 0。 |
| % | 定义基于包含它的块级对象的百分比最小高度。 |
| inherit | 规定应该从父元素继承 min-height 属性的值。 |
