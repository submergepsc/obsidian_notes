## 实例


匹配  的父元素的第一个元素


```css
p:first-child
{
    background-color:yellow;
}
```

## 定义和用法


:first-child 选择器匹配其父元素中的第一个子元素。


---


## 浏览器支持


表格中的数字表示支持该属性的第一个浏览器版本号。


| 选择器 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| :first-child | 4.0 | 7.0 | 3.0 | 3.1 | 9.6 |


注意:** :first-child在IE8和更早版本IE版本中必须声明[](https://www.runoob.com/../tags/tag-doctype.html)
