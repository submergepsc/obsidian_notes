[![完整CSS选择器参考手册](https://www.runoob.com/images/up.gif) 完整CSS选择器参考手册](https://www.runoob.com/css-selectors.html)


## 实例


输入的值在指定区间内时，设置指定样式:


```css
input:in-range
	{
	border:2px solid yellow;
	}
```

## 定义和使用


:in-range 选择器用于标签的值在指定区间值时显示的样式。


注意：** :in-range 选择器只作用于能指定区间值的元素，例如 input 元素中的 min 和 max 属性。


---


## 浏览器支持


表格中的数字表示支持该属性的第一个浏览器版本号。


| 选择器 |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| :in-range | 10.0 | 不支持 | 28.0 | 5.2 | 11.0 |


---


## CSS 语法


:in-range**{
*css 声明*;
}
