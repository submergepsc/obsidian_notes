# CSS3 border-bottom-left-radius 属性

- Source: https://www.runoob.com/cssref/css3-pr-border-bottom-left-radius.html

**
## 实例


为div元素的左下角添加圆角边框：


```css
div
{
    border:2px solid;
    border-bottom-left-radius:2em;
}
```

## 属性定义及使用说明


border-bottom-left-radius 属性定义左下角边框的形状。


提示:** 这个属性允许你添加元素的圆角边框！


| 默认值: | 0 |
| --- | --- |
| 继承: | no |
| 版本: | CSS3 |
| JavaScript 语法: | object object.style.borderBottomRightRadius="5px" |

**
---


## 语法


border-bottom-left-radius: *length*|*%* [*length*|*%*];

注意：**注如果您设置了两个值，第一个用于下边框，第二个用于左边框。 如果省略第二个值，则从第一个值复制。 当其中一个值为 0 时，圆角将不被设置，这时这个角将展示为直角。


```
/* 圆形 */
/* border-bottom-left-radius: radius */
border-bottom-left-radius: 3px;

/* 椭圆形 */
/* border-bottom-left-radius: 水平方向 垂直方向 */
border-bottom-left-radius: 0.5em 1em;

border-bottom-left-radius: inherit;
```


| 值 | 说明 |
| --- | --- |
| length | 定义右下角的形状。 |
| % | 使用%定义右下角的形状。 |
