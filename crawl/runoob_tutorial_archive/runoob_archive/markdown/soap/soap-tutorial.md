# SOAP 教程

- Source: https://www.runoob.com/soap/soap-tutorial.html

**

SOAP 是一种简单的基于 XML 的协议，它使应用程序通过 HTTP 来交换信息。


在我们的 SOAP 教程中，你将了解到什么是 SOAP，以及它如何在应用程序之间交换信息。


[现在开始学习 SOAP!](https://www.runoob.com/soap-intro.html)**


## 内容列表


[SOAP 简介](https://www.runoob.com/soap-intro.html)** 本章讲解 SOAP 的概念和作用。


[SOAP 语法](https://www.runoob.com/soap-syntax.html) 本章讲解 SOAP 的构建模块和 SOAP 的语法规则。


[SOAP Envelope 元素](https://www.runoob.com/soap-envelope.html) 本章讲解 SOAP 的 Envelope 元素。


[SOAP Header 元素](https://www.runoob.com/soap-header.html) 本章讲解 SOAP 的 Header 元素。


[SOAP Body 元素](https://www.runoob.com/soap-body.html) 本章讲解 SOAP 的 Body 元素。


[SOAP Fault 元素](https://www.runoob.com/soap-fault.html) 本章讲解 SOAP 的 Fault 元素。


[SOAP HTTP Binding](https://www.runoob.com/soap-httpbinding.html) 本章是对 SOAP HTTP 绑定的简介。


[SOAP 实例](https://www.runoob.com/soap-example.html) 本章介绍了一个 SOAP 实例。


[SOAP 总结](https://www.runoob.com/soap-summary.html) 本节是对您在本教程所学内容的一个总结，并为您推荐了下一步应该学习的内容。
