# Firebug动态执行JavaScript

- Source: https://www.runoob.com/firebug/firebug-execute-javascript.html

---

**

** Firebug 官网宣布已停止继续开发、更新维护 Firebug 的通知，邀请大家使用 Firefox 内置工具 [DevTools](https://developer.mozilla.org/en-US/docs/Tools)。


您可以使用Firebug来编写并实时执行一个JavaScript。

这是为了测试，并确保该脚本工作正常，这是将JavaScript代码部署在生产环境前的好方法。

打开Firebug > Script(脚本) > 显示命令行，代码如下所示：


```
alert("w3cschool.cc")
```


![execute-js-1](https://www.runoob.com/wp-content/uploads/2013/12/execute-js-1.jpg)

按Enter键后，马上你就能看到代码的输出。如图所示：

![execute-js-2](https://www.runoob.com/wp-content/uploads/2013/12/execute-js-2.jpg)
