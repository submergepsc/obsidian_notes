# 响应式 Web 设计 - 视频(Video)

- Source: https://www.runoob.com/css/css-rwd-videos.html

## 使用 width 属性


如果 width 属性设置为 100%，视频播放器会根据屏幕大小自动调整比例：


## 实例


```css
video {
    width: 100%;    height: auto;
}
```


	**[尝试一下 »](https://www.runoob.com/try/tryit.php?filename=tryresponsive_video2)


注意在以上实例中，视频播放器根据屏幕大小自动调整比例，且可以比原始尺寸大。更多情况下我们可以使用 max-width 属性来替代。


---


## 使用 max-width 属性


如果 max-width 属性设置为 100%, 视频播放器会根据屏幕自动调整比例，但不会超过其原始大小：


## 实例


```css
video {
    max-width: 100%;    height: auto;
}
```



[尝试一下 »](https://www.runoob.com/try/tryit.php?filename=tryresponsive_video)


---


## 在网页中添加视频

我们可以在网页中添加视频。以下实例视频根据 div 区域大小自动调整并占满整个 div 区域：


## 实例


```css
video {
    width: 100%;    height: auto;
}
```
