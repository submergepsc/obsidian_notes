- Source: https://www.runoob.com/charsets/ref-utf-math.html

---


## 范围：十进制 8704-8959，十六进制 2200-22FF。


如果您想要在 HTML 中显示这些字符，您可以使用下表中的 HTML 实体。


如果字符没有 HTML 实体，您可以使用十进制或十六进制引用。


## 实例


```
<p>我将显示 &sum;<p>
<p>我将显示 &#8721;<p>
<p>我将显示 &#x2211;<p>
```


**

## 结果如下：


```
我将显示 ∑
我将显示 ∑
我将显示 ∑
```
