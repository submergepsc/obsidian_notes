# UTF-8 方块元素（Block Elements）

- Source: https://www.runoob.com/charsets/ref-utf-block.html

---


## 范围：十进制 9600-9631，十六进制 2580-259F。


如果您想要在 HTML 中显示这些字符，您可以使用下表中的 HTML 实体。


如果字符没有 HTML 实体，您可以使用十进制或十六进制引用。


## 实例


```
<p>我将显示 &#9602;<p>
<p>我将显示 &#x2582;<p>
```


**

## 结果如下：


```
我将显示 ▂
我将显示 ▂
```


[尝试一下 »](https://www.runoob.com/try/try.php?filename=tryutf_block)


并非下表中的所有实体都能在所有的浏览器中正确地显示。


目前，IE 11 是唯一一个能正确显示所有 HTML5 实体的浏览器。
