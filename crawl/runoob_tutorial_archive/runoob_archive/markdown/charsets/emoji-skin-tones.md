# Emoji 肤色

- Source: https://www.runoob.com/charsets/emoji-skin-tones.html

Emoji 可以使用以下五种不同来修改表情符号：


🏿 🏿 深色肤色** 🏾 🏾 中等深肤色 🏽 🏽 中等肤色 🏼 🏼 中等浅肤色 🏻 🏻 浅肤色


Emoji 添加肤色，需要在 Emoji 符号后面添加一个肤色十进制实体：


## 实例


```
<p>&#9757; 不设置肤色</p>
<p>&#9757;&#127999; 深色</p>
<p>&#9757;&#127998; 中等深色</p>
<p>&#9757;&#127997; 中等色</p>
<p>&#9757;&#127996; 中等浅色</p>
<p>&#9757;&#127995; 浅肤色</p>
```
