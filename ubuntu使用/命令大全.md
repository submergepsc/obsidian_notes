# 解压压缩
下面这几个都是 Linux 里常见的**压缩、解压、打包**命令。
核心区别先记住一句：
```text
tar 负责“打包”
gzip 负责“压缩单个文件”
zip 负责“打包 + 压缩”
```
# 1. `tar`
`tar` 的全称是 **tape archive**，主要作用是：**把多个文件或目录归档成一个文件**。
严格来说，`tar` 本身主要是**打包**，不是压缩。
但它可以配合 `gzip`、`bzip2`、`xz` 等工具一起压缩。
## 常见文件格式
```text
.tar        只打包，不压缩
.tar.gz     打包后用 gzip 压缩
.tgz        .tar.gz 的简写
.tar.bz2    打包后用 bzip2 压缩
.tar.xz     打包后用 xz 压缩
```
## 常用参数
| 参数   | 含义            |
| ---- | ------------- |
| `-c` | create，创建归档   |
| `-x` | extract，解包/解压 |
| `-v` | verbose，显示过程  |
| `-f` | file，指定文件名    |
| `-z` | 使用 gzip       |
| `-j` | 使用 bzip2      |
| `-J` | 使用 xz         |
| `-t` | 查看归档内容        |

## 压缩目录为 `.tar.gz`
```bash
tar -czvf archive.tar.gz dir/
```
解释：
```text
-c  创建归档
-z  使用 gzip 压缩
-v  显示过程
-f  指定输出文件名
```
意思是：把 `dir/` 目录打包压缩成 `archive.tar.gz`。
## 解压 `.tar.gz`
```bash
tar -xzvf archive.tar.gz
```
解释：
```text
-x  解压/解包
-z  使用 gzip
-v  显示过程
-f  指定文件名
```
## 解压到指定目录
```bash
tar -xzvf archive.tar.gz -C /tmp/
```
意思是：解压到 `/tmp/` 目录。
注意：`/tmp/` 必须已经存在。
## 查看压缩包内容，不解压
```bash
tar -tzvf archive.tar.gz
```
# 2. `gzip`
`gzip` 用来压缩文件，生成 `.gz` 文件。
注意：`gzip` 通常只压缩**单个文件**，不直接压缩目录。
## 压缩文件
```bash
gzip file.txt
```
执行后：
```text
file.txt 变成 file.txt.gz
```
原来的 `file.txt` 默认会消失，只保留压缩后的 `file.txt.gz`。
## 保留原文件压缩
```bash
gzip -k file.txt
```
执行后会同时保留：
```text
file.txt
file.txt.gz
```
## 查看 `.gz` 文件信息
```bash
gzip -l file.txt.gz
```
# 3. `gunzip`
`gunzip` 是 `gzip` 的解压命令。
## 解压 `.gz`
```bash
gunzip file.txt.gz
```
执行后：
```text
file.txt.gz 变回 file.txt
```
## 等价写法
下面两个命令等价：
```bash
gunzip file.txt.gz
```
```bash
gzip -d file.txt.gz
```
其中 `-d` 表示 decompress，解压。
# 4. `zip`
`zip` 是常见的压缩格式，Windows、macOS、Linux 都支持。
它和 `tar + gzip` 不一样，`zip` 本身就可以做到：
```text
打包 + 压缩
```
## 压缩单个文件
```bash
zip archive.zip file.txt
```
## 压缩多个文件
```bash
zip archive.zip file1.txt file2.txt file3.txt
```
## 压缩目录
压缩目录时要加 `-r`：
```bash
zip -r archive.zip dir/
```
解释：
```text
-r  recursive，递归处理目录
```
否则只会压缩目录名，不会把目录里的文件都放进去。
# 5. `unzip`
`unzip` 用来解压 `.zip` 文件。
你写的：
```text
unzipjp
```
应该是笔误，通常是：
```text
unzip
```
## 解压 zip 文件
```bash
unzip archive.zip
```
## 解压到指定目录
```bash
unzip archive.zip -d /tmp/
```
## 查看 zip 内容，不解压
```bash
unzip -l archive.zip
```
# 对比总结
| 命令       | 主要作用         | 常见格式                         |
| -------- | ------------ | ---------------------------- |
| `tar`    | 打包，也可配合压缩    | `.tar`, `.tar.gz`, `.tar.xz` |
| `gzip`   | 压缩单个文件       | `.gz`                        |
| `gunzip` | 解压 `.gz` 文件  | `.gz`                        |
| `zip`    | 打包并压缩        | `.zip`                       |
| `unzip`  | 解压 `.zip` 文件 | `.zip`                       |

# 最常用记法
## Linux 项目目录打包
```bash
tar -czvf project.tar.gz project/
```
## 解压 Linux 项目包
```bash
tar -xzvf project.tar.gz
```
## 压缩成 Windows 也方便打开的格式
```bash
zip -r project.zip project/
```
## 解压 zip
```bash
unzip project.zip
```
# 实用建议
在 Linux 服务器之间传文件，常用：
```bash
tar -czvf archive.tar.gz dir/
```
如果要发给 Windows 用户，常用：
```bash
zip -r archive.zip dir/
```
