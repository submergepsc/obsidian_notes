# 00 实验总览与环境准备
## 1. 实验目标
本实验包含两条主线：
```text
第一条：Linux 常用命令
  学会在终端里完成日常文件、文本、系统、网络、压缩、权限操作。
第二条：ARM 汇编语言入门
  学会把 C 语言编译成汇编，观察 x86-64 和 ARM64/AArch64 的区别。
```
你最终应该能做到：
- 会用 `pwd`、`ls`、`cd`、`mkdir`、`cp`、`mv`、`rm` 管理文件和目录。
- 会用 `cat`、`less`、`head`、`tail`、`grep`、`find` 查看和搜索内容。
- 会用 `tar`、`gzip`、`zip`、`unzip` 打包压缩文件。
- 会用 `uname`、`df`、`du`、`free`、`ps`、`top` 查看系统状态。
- 会用 `gcc -S` 生成 x86-64 汇编文件。
- 会用 `aarch64-linux-gnu-gcc -S` 生成 ARM64/AArch64 汇编文件。
- 会用 `objdump -d` 和 `aarch64-linux-gnu-objdump -d` 反汇编目标文件。
- 能解释 `add w0, w0, w1` 为什么对应 C 语言里的 `return a + b;`。
## 2. 推荐实验目录
建议创建单独实验目录，所有文件都放进去：
```bash
mkdir -p ~/linux-arm-lab/week2
cd ~/linux-arm-lab/week2
pwd
```
解释：
```text
mkdir -p   创建多级目录，如果中间目录不存在就一起创建
cd         进入目录
pwd        显示当前目录
```
推荐目录结构：
```text
~/linux-arm-lab/week2/
├── add.c
├── add-x86.s
├── add-x86.o
├── add-arm64.s
├── add-arm64.o
├── hello.c
├── hello-x86
└── hello-arm64
```
## 3. 检查系统信息
先查看当前系统和 CPU 架构：
```bash
uname -a
uname -m
```
常见输出：
```text
x86_64
```
表示当前机器是 x86-64 架构。
如果输出是：
```text
aarch64
```
表示当前机器本身就是 ARM64/AArch64 架构。
## 4. 安装基础编译环境
Ubuntu 上通常这样安装：
```bash
sudo apt update
sudo apt install build-essential binutils
```
其中：

| 包名 | 作用 |
| --- | --- |
| `build-essential` | 安装 GCC、G++、make 等基础编译工具 |
| `binutils` | 提供 `objdump`、`as`、`ld` 等二进制工具 |

检查：
```bash
gcc --version
objdump --version
make --version
```
## 5. 安装 ARM64 交叉编译环境
如果你的主机是 x86-64，但要生成 ARM64 程序，需要安装交叉编译器：
```bash
sudo apt install crossbuild-essential-arm64 gcc-aarch64-linux-gnu binutils-aarch64-linux-gnu
```
检查：
```bash
aarch64-linux-gnu-gcc --version
aarch64-linux-gnu-objdump --version
```
这些命令的含义：

| 命令 | 作用 |
| --- | --- |
| `aarch64-linux-gnu-gcc` | 生成 ARM64/AArch64 Linux 程序 |
| `aarch64-linux-gnu-objdump` | 反汇编 ARM64/AArch64 目标文件 |

> [!note]
> `aarch64` 基本可以理解为 64 位 ARM。课堂里说的 ARM64，在 Linux 工具链里经常写作 AArch64。
## 6. 本实验不要混淆的几个概念
### GCC
`gcc` 是本机 C 编译器。你的电脑如果是 x86-64，`gcc` 默认生成 x86-64 程序。
```bash
gcc -o hello hello.c
```
### 交叉编译器
`aarch64-linux-gnu-gcc` 是 ARM64 交叉编译器。即使你在 x86-64 电脑上运行它，它生成的也是 ARM64 程序。
```bash
aarch64-linux-gnu-gcc -o hello-arm64 hello.c
```
### 汇编文件
`.s` 文件是汇编文本文件，可以直接用编辑器查看：
```bash
gcc -S -o add.s add.c
less add.s
```
### 目标文件
`.o` 文件是二进制目标文件，不能直接用普通文本方式阅读：
```bash
gcc -c -o add.o add.c
file add.o
objdump -d add.o
```
## 7. 最小实验检查
创建测试文件：
```bash
cat > add.c <<'EOF'
int add(int a, int b)
{
    return a + b;
}
EOF
```
生成 x86 汇编：
```bash
gcc -S -O1 -o add-x86.s add.c
```
生成 ARM64 汇编：
```bash
aarch64-linux-gnu-gcc -S -O1 -o add-arm64.s add.c
```
查看结果：
```bash
ls -lah
cat add.c
less add-x86.s
less add-arm64.s
```
如果这些命令都能完成，环境基本没有问题。
