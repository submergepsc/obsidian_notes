# 03 文本查看查找与处理
## 1. 为什么文本处理很重要
Linux 中大量配置、日志、源码都是文本文件。熟练查看和搜索文本，是使用 Linux 的基础能力。
常见场景：
- 查看 C 源码：`cat add.c`
- 查看长日志：`less app.log`
- 搜索错误：`grep "error" app.log`
- 统计行数：`wc -l file.txt`
- 比较两个文件：`diff old.txt new.txt`
## 2. `cat`
`cat` 用来输出整个文件内容。
```bash
cat file.txt
```
适合：
- 文件比较短。
- 想快速确认文件内容。
不适合：
- 文件很长，刷屏太快。
创建并查看文件：
```bash
echo "hello" > file.txt
cat file.txt
```
连接多个文件：
```bash
cat a.txt b.txt
```
## 3. `less`
`less` 用来分页查看长文件。
```bash
less app.log
```
常用按键：

| 按键 | 作用 |
| --- | --- |
| `空格` | 下一页 |
| `b` | 上一页 |
| `j` | 下一行 |
| `k` | 上一行 |
| `/关键词` | 搜索 |
| `n` | 下一个搜索结果 |
| `N` | 上一个搜索结果 |
| `q` | 退出 |

查看汇编文件也适合用 `less`：
```bash
less add-arm64.s
```
## 4. `head` 和 `tail`
查看文件开头：
```bash
head file.txt
head -20 file.txt
```
查看文件末尾：
```bash
tail file.txt
tail -20 file.txt
```
实时追踪日志：
```bash
tail -f app.log
```
常见用途：
```bash
tail -f /var/log/syslog
```
> [!note]
> `tail -f` 会一直等待新内容。退出用 `Ctrl + C`。
## 5. `grep`
`grep` 用于按关键词搜索文本行。
基本用法：
```bash
grep "hello" file.txt
```
显示行号：
```bash
grep -n "hello" file.txt
```
忽略大小写：
```bash
grep -i "error" app.log
```
递归搜索目录：
```bash
grep -r "main" .
```
只显示文件名：
```bash
grep -rl "main" .
```
常用参数：

| 参数 | 含义 |
| --- | --- |
| `-n` | 显示行号 |
| `-i` | 忽略大小写 |
| `-r` | 递归搜索目录 |
| `-l` | 只列出匹配的文件名 |
| `-v` | 反向匹配，显示不包含关键词的行 |
| `-E` | 使用扩展正则表达式 |

例子：
```bash
grep -n "add" add-arm64.s
grep -nE "add|ret" add-arm64.s
```
## 6. `find`
`find` 用来按条件查找文件。
查找 `.c` 文件：
```bash
find . -name "*.c"
```
查找普通文件：
```bash
find . -type f
```
查找目录：
```bash
find . -type d
```
查找大于 10MB 的文件：
```bash
find . -type f -size +10M
```
查找并显示详细信息：
```bash
find . -name "*.c" -ls
```
常用条件：

| 条件 | 含义 |
| --- | --- |
| `-name` | 按名称匹配 |
| `-type f` | 普通文件 |
| `-type d` | 目录 |
| `-size +10M` | 大于 10MB |
| `-mtime -1` | 1 天内修改过 |

## 7. `wc`
`wc` 用来统计。
```bash
wc file.txt
```
输出通常是：
```text
行数 单词数 字节数 文件名
```
只看行数：
```bash
wc -l file.txt
```
只看字节数：
```bash
wc -c file.txt
```
统计当前目录下 `.c` 文件数量：
```bash
find . -name "*.c" | wc -l
```
## 8. `sort` 和 `uniq`
排序：
```bash
sort names.txt
```
去重前通常先排序：
```bash
sort names.txt | uniq
```
统计重复次数：
```bash
sort names.txt | uniq -c
```
按数字排序：
```bash
sort -n numbers.txt
```
倒序：
```bash
sort -r names.txt
```
## 9. `cut`
`cut` 用于按列提取。
假设 `data.csv`：
```text
name,age,city
Alice,18,Beijing
Bob,20,Shanghai
```
提取第 1 列：
```bash
cut -d',' -f1 data.csv
```
解释：
```text
-d','   使用逗号作为分隔符
-f1     取第 1 列
```
提取第 1 和第 3 列：
```bash
cut -d',' -f1,3 data.csv
```
## 10. `diff`
`diff` 用来比较两个文件差异。
```bash
diff old.txt new.txt
```
更易读的格式：
```bash
diff -u old.txt new.txt
```
常见用途：
- 比较修改前后的配置。
- 比较两个汇编文件。
- 比较 `-O0` 和 `-O1` 生成的汇编差异。
例子：
```bash
gcc -S -O0 -o add-O0.s add.c
gcc -S -O1 -o add-O1.s add.c
diff -u add-O0.s add-O1.s
```
## 11. 实验练习
创建示例文件：
```bash
cat > log.txt <<'EOF'
info: boot
warning: disk low
error: open failed
info: done
EOF
```
完成以下命令：
```bash
cat log.txt
less log.txt
grep -n "error" log.txt
grep -i "WARNING" log.txt
head -2 log.txt
tail -2 log.txt
wc -l log.txt
```
思考：
- 哪些命令只是查看？
- 哪些命令会搜索？
- 哪些命令会统计？
