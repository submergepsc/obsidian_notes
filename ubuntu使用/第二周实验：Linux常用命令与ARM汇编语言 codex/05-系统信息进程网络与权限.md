# 05 系统信息进程网络与权限
## 1. 系统信息
查看系统和内核：
```bash
uname -a
```
只看机器架构：
```bash
uname -m
```
常见结果：
```text
x86_64    64 位 x86 架构
aarch64   64 位 ARM 架构
```
查看当前用户：
```bash
whoami
id
```
查看主机名：
```bash
hostname
```
查看时间：
```bash
date
```
查看系统运行时间：
```bash
uptime
```
## 2. 磁盘空间
### `df`
查看文件系统剩余空间：
```bash
df -h
```
解释：
```text
-h  human-readable，用 GB/MB 显示
```
常看列：

| 列 | 含义 |
| --- | --- |
| `Filesystem` | 文件系统或磁盘分区 |
| `Size` | 总大小 |
| `Used` | 已用 |
| `Avail` | 可用 |
| `Use%` | 使用百分比 |
| `Mounted on` | 挂载点 |

### `du`
查看目录占用：
```bash
du -sh .
du -sh ~/Downloads
```
解释：
```text
-s  summary，只显示总计
-h  human-readable
```
查看当前目录下每个项目大小：
```bash
du -h --max-depth=1
```
## 3. 内存和 CPU
查看内存：
```bash
free -h
```
动态查看进程：
```bash
top
```
如果安装了 `htop`：
```bash
htop
```
`top` 常用按键：

| 按键 | 作用 |
| --- | --- |
| `q` | 退出 |
| `P` | 按 CPU 排序 |
| `M` | 按内存排序 |
| `k` | 杀进程 |

## 4. 进程管理
查看所有进程：
```bash
ps aux
```
搜索某个进程：
```bash
ps aux | grep bash
```
更精确：
```bash
pgrep -a bash
```
结束进程：
```bash
kill PID
```
强制结束：
```bash
kill -9 PID
```
> [!warning]
> `kill -9` 是强制杀死，进程没有机会清理临时文件或保存状态。优先尝试普通 `kill`。
## 5. 网络命令
### `ip`
查看 IP 地址：
```bash
ip addr
```
查看路由：
```bash
ip route
```
### `ping`
测试网络连通：
```bash
ping -c 4 8.8.8.8
ping -c 4 example.com
```
解释：
```text
-c 4  只发送 4 次
```
### `curl`
查看网页响应头：
```bash
curl -I https://example.com
```
下载到文件：
```bash
curl -L -o page.html https://example.com
```
### `wget`
下载文件：
```bash
wget https://example.com/file.zip
```
### `ss`
查看监听端口：
```bash
ss -ltnp
```
含义：
```text
-l  listening，只看监听端口
-t  TCP
-n  不解析名字，直接显示数字端口
-p  显示进程
```
## 6. 权限基础
查看权限：
```bash
ls -l
```
示例：
```text
-rwxr-xr-- 1 loviya loviya 1234 May 15 script.sh
```
第一段可以拆开：
```text
-   普通文件
rwx 所有者权限
r-x 所属组权限
r-- 其他用户权限
```
权限含义：

| 字符 | 含义 |
| --- | --- |
| `r` | read，读取 |
| `w` | write，写入 |
| `x` | execute，执行 |
| `-` | 没有对应权限 |

## 7. `chmod`
给脚本添加执行权限：
```bash
chmod +x script.sh
```
数字权限：
```bash
chmod 755 script.sh
```
数字含义：
```text
4 = read
2 = write
1 = execute
```
所以：
```text
7 = 4 + 2 + 1 = rwx
5 = 4 + 1     = r-x
5 = 4 + 1     = r-x
```
`755` 表示：
```text
所有者 rwx
所属组 r-x
其他人 r-x
```
## 8. `chown`
修改文件所有者：
```bash
sudo chown user:group file.txt
```
例子：
```bash
sudo chown loviya:loviya file.txt
```
递归修改目录：
```bash
sudo chown -R loviya:loviya project/
```
> [!warning]
> 不要随便对系统目录执行 `chown -R`。路径写错可能破坏系统权限。
## 9. `sudo`
`sudo` 表示以管理员权限执行命令。
常见用途：
```bash
sudo apt update
sudo apt install gcc
sudo systemctl status ssh
```
原则：
- 能不用 `sudo` 就不用。
- 用 `sudo` 前先确认命令和路径。
- 不要直接复制网上的危险命令执行。
