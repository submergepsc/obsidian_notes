# 02 文件目录与路径操作
## 1. Linux 文件系统的基本观念
Linux 里所有东西都从根目录 `/` 开始。
常见目录：

| 目录 | 作用 |
| --- | --- |
| `/` | 根目录 |
| `/home` | 普通用户家目录所在位置 |
| `/home/loviya` | 用户 `loviya` 的家目录 |
| `/etc` | 系统配置文件 |
| `/usr` | 系统软件和共享资源 |
| `/bin`、`/usr/bin` | 常用可执行命令 |
| `/tmp` | 临时文件 |
| `/var` | 日志、缓存、变化数据 |

查看根目录：
```bash
ls /
```
查看家目录：
```bash
ls ~
```
## 2. 绝对路径和相对路径
### 绝对路径
从 `/` 开始的路径叫绝对路径：
```text
/home/loviya/notes/obsidian_notes
```
不管你当前在哪个目录，这个路径都指向同一个位置。
### 相对路径
不从 `/` 开始的路径叫相对路径：
```text
notes/obsidian_notes
```
它是相对于当前目录来理解的。
### 特殊路径
| 写法 | 含义 |
| --- | --- |
| `.` | 当前目录 |
| `..` | 上一级目录 |
| `~` | 当前用户家目录 |
| `-` | 上一次所在目录，常用于 `cd -` |

例子：
```bash
pwd
cd ..
pwd
cd -
```
## 3. `pwd`
`pwd` 的意思是 print working directory，显示当前工作目录。
```bash
pwd
```
示例输出：
```text
/home/loviya/linux-arm-lab/week2
```
什么时候用：
- 不确定自己在哪个目录时。
- 执行删除、移动等危险操作前。
- 写实验报告时记录当前实验路径。
## 4. `ls`
`ls` 用来列出目录内容。
常用：
```bash
ls
ls -l
ls -a
ls -lah
```
参数解释：

| 参数 | 含义 |
| --- | --- |
| `-l` | long，显示详细信息 |
| `-a` | all，显示隐藏文件 |
| `-h` | human-readable，以 KB/MB/GB 显示大小 |
| `-R` | recursive，递归列出子目录 |

示例：
```bash
ls -lah
```
输出中每列的大致含义：
```text
-rw-r--r-- 1 loviya loviya 123 May 15 10:00 file.txt
```
```text
-rw-r--r--   权限
1           硬链接数
loviya      所有者
loviya      所属组
123         文件大小
May 15...   修改时间
file.txt    文件名
```
## 5. `cd`
`cd` 用来切换目录。
常用：
```bash
cd /home/loviya
cd ..
cd ~
cd -
```
解释：

| 命令 | 含义 |
| --- | --- |
| `cd /home/loviya` | 进入指定绝对路径 |
| `cd ..` | 回到上一级目录 |
| `cd ~` | 回到家目录 |
| `cd -` | 回到上一次所在目录 |

注意：
```bash
cd dir
```
要求 `dir` 必须是目录，不能是普通文件。
## 6. `mkdir`
`mkdir` 用来创建目录。
创建单个目录：
```bash
mkdir lab
```
创建多级目录：
```bash
mkdir -p lab/week2/src
```
解释：
```text
-p  parent，不存在的父目录也一起创建；已存在时不报错
```
建议实验中经常用：
```bash
mkdir -p ~/linux-arm-lab/week2
```
## 7. `touch`
`touch` 常用于创建空文件：
```bash
touch note.txt
```
如果文件已经存在，`touch` 会更新它的修改时间。
查看时间变化：
```bash
ls -l note.txt
touch note.txt
ls -l note.txt
```
## 8. `cp`
`cp` 用来复制文件或目录。
复制文件：
```bash
cp a.txt b.txt
```
复制到目录：
```bash
cp a.txt backup/
```
复制目录：
```bash
cp -r dir1 dir2
```
常用参数：

| 参数 | 含义 |
| --- | --- |
| `-r` | recursive，递归复制目录 |
| `-i` | 覆盖前询问 |
| `-v` | 显示复制过程 |
| `-a` | archive，尽量保留权限、时间等属性 |

安全写法：
```bash
cp -iv a.txt b.txt
cp -av project project-backup
```
## 9. `mv`
`mv` 有两个用途：
```text
移动文件
重命名文件
```
重命名：
```bash
mv old.txt new.txt
```
移动：
```bash
mv new.txt backup/
```
移动并改名：
```bash
mv old.txt backup/new.txt
```
常用参数：
```bash
mv -i old.txt new.txt
mv -v file.txt backup/
```
## 10. `rm`
`rm` 用来删除文件。
删除文件：
```bash
rm file.txt
```
删除目录：
```bash
rm -r dir
```
常用参数：

| 参数 | 含义 |
| --- | --- |
| `-r` | 递归删除目录 |
| `-i` | 删除前询问 |
| `-f` | force，强制删除，不提示 |
| `-v` | 显示删除过程 |

> [!warning]
> `rm -rf` 非常危险。它不会进入回收站，路径写错可能直接删除大量文件。
建议初学时用：
```bash
rm -i file.txt
rm -ri dir
```
## 11. 一次完整练习
```bash
mkdir -p ~/linux-command-practice
cd ~/linux-command-practice
pwd
touch a.txt
echo "hello linux" > a.txt
cat a.txt
cp a.txt b.txt
mkdir backup
mv b.txt backup/
ls -lah
ls -lah backup
rm -i a.txt
rm -ri backup
```
练习目标：
- 能解释每一条命令做了什么。
- 能说出 `a.txt`、`b.txt`、`backup/` 分别在哪一步创建或移动。
- 删除前能确认当前路径。
